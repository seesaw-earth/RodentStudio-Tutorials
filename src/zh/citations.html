引用数据的三条规则

  1. 用 DOI 引用数据集本身，放进参考文献；同时引用数据集作者要求引用的论文。数据集和论文是两项独立的成果。
  2. 引用软件时写明版本。如 “Ultralytics YOLO26”“RodentStudio 0.7.1”“coremltools 9.0”：不同版本的结果可能不同。
  3. 说明做了哪些改动、标签从哪里来。CC BY 4.0 要求署名、给出许可链接并注明改动。这里的标签是由 DeepLabCut 和 JAX 网络的预测统一、过滤而来，应如实写明，不要让读者以为是人工标注。

使用了 TST 检测器

引用 RodentStudio [S1] 和 Ultralytics YOLO11 [S3]，并说明使用的是 YOLO 检测器还是经典检测器（RodentStudio 的导出文件会记录）。RodentFlow 流程不需要引用模型；在方法中描述经典追踪器并引用 RodentStudio 即可。

引用本教程中的检验

  • CalMS21 零样本测试：CalMS21 数据集 [D5] 和论文 [P9]；MARS 关键点来自 MARS [P10]。
  • 高架十字迷宫预试验：Sturman 等 2020 [P11] 及视频记录 [D6]；如使用了 DLCAnalyzer 的脚本，再引用 [S5]。

  • 导出为 Core ML：coremltools [S4]。

方法部分示例

请按实际做法修改，方括号内的内容全部替换。英文版示例见英文页。

姿态估计。使用 RodentStudio [版本] [S1] 通过 Core ML 在本机运行 MousePose6 模型（MousePose6_960_int8，8 位权重的 YOLO26n-pose 网络 [S2]），逐帧估计六个身体关键点（鼻尖、左耳、右耳、颈部、身体中心和尾根）。该模型在四个公开俯视数据集 [D1–D4] 的 36 段视频共 6,140 帧上训练，标签来自这些数据集随附的 DeepLabCut [P4, P5] 与 JAX 姿态网络 [P3] 预测，经统一关键点定义和质量过滤后使用；因此标签由模型生成，而非人工标注。在同一批数据集的留出视频上，该模型检出 94.6 % 的小鼠，已检出小鼠的关键点中有 96.1 % 与参照标签相差不到 0.1 个体长。我们在自己的录像中每段随机抽取 [数量] 帧检查了关键点位置［，并将得到的指标与 [数量] 段视频的盲法人工评分进行了比较］。

资源许可或条款在这里意味着什么
ETH 数据集 [D1]、[D2]、[D6]CC BY 4.0允许再利用（包括派生的标签和模型），需署名、给出许可链接并注明改动。
JAX 数据集 [D3]、[D4]CC BY-NC-SA 4.0须署名、仅限非商业使用、改编作品须以相同许可共享。MousePose6 有 3,500 张训练图来自这两个数据集，除非 JAX 另行授权，应把 MousePose6 视为仅限非商业使用；见教程 1。
JAX 姿态模型及其训练数据（Zenodo 记录 6380163）“Other (Non-Commercial)”适用于该发布本身。MousePose6 使用的是 [D3]、[D4] 随附的关键点文件，而不是这个发布；那些文件本身是 CC BY-NC-SA 4.0。
CalMS21 [D5]CC BY 4.0只用于外部检验。
PhysioNet 数据集 [D7]Open Data Commons Attribution（ODC-By）1.0需署名；只用于演示视频。
Ultralytics YOLO 代码和预训练权重 [S2]、[S3]AGPL-3.0，或 Ultralytics 企业许可Ultralytics 声明 AGPL 条款延伸到用其代码训练的模型；闭源分发需要企业许可。
